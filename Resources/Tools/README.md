# Makera Bridge Z1 tool library

These FreeCAD definitions use published Makera dimensions and the matching
OpenSpindle Makera catalog. They use FreeCAD's built-in shapes. Library numbers
are suggestions for CAM tool controllers. Select the tool you actually have
and set feeds and speeds for the material and operation.
